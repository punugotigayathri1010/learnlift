PROJECT STORY

LearnLift is an early-warning
student success platform.

The supplied dataset contains learner demographics, academic activity, assessment behaviour and engagement indicators. LearnLift turns those raw signals into a visual analytics experience.

01

Data

32,593 learner-module records and 20 variables are connected directly to the application.

02

Intelligence

A Random Forest classifier learns from pre-outcome features and returns a probability-based risk estimate.

03

Experience

The interface uses a sidebar workspace, live KPIs, interactive charts and an assessment workflow rather than a traditional static project layout.
